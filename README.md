## Overview

### The challenge

Users should be able to:

- Complete each step of the subscription form.
- Go back to previous steps and update their selections.
- Select between different subscription plans.
- Switch between monthly and yearly billing options.
- See the 2-month-free offer when yearly billing is selected.
- Select additional services (add-ons).
- View a summary of their selected plan and add-ons.
- See the total price update dynamically.
- Confirm their subscription and view a thank-you message.
- View an optimal layout depending on their device's screen size.
- See hover and focus states for interactive elements.
- Receive validation messages when required fields are missing or the email address is invalid.

### What I learned

While building this project, I learned how to:

- Create a multi-step form using HTML and CSS.
- Build responsive layouts using Flexbox and media queries.
- Navigate between form steps using JavaScript.
- Handle user interactions using event listeners.
- Update subscription prices dynamically based on billing frequency.
- Calculate the total price based on selected plans and add-ons.
- Validate user input using JavaScript.
- Manipulate DOM elements and update their content dynamically.
